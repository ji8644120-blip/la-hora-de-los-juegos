Sobre Nosotros

La Hora de los Juegos es un proyecto creado con el propósito de ofrecer un espacio divertido, sencillo e interactivo donde los usuarios puedan disfrutar de diferentes juegos desde una misma página web.

Este proyecto hace parte de nuestro proceso de formación en el SENA, donde ponemos en práctica nuestros conocimientos sobre programación, diseño y desarrollo web.

Skills que aprendimos

Durante el desarrollo de este proyecto adquirimos y fortalecimos diferentes habilidades relacionadas con el desarrollo web y la programación.

🌐

HTML

Aprendimos a crear la estructura y el contenido de las páginas web.

🎨

CSS

Aprendimos a diseñar las páginas, aplicar colores, organizar elementos y adaptar el contenido a diferentes dispositivos.

⚡

JavaScript

Aprendimos a agregar interacción, lógica y funcionamiento a los juegos.

🧠

Lógica de programación

Trabajamos con algoritmos, variables, condiciones, ciclos y funciones para solucionar problemas.

🐙

GitHub y GitHub Pages

Aprendimos a organizar nuestro proyecto, administrar archivos y publicar nuestra página web en Internet.

✨

Diseño de interfaces

Aprendimos a organizar visualmente los elementos para crear una experiencia sencilla y agradable para los usuarios.

🎯

Nuestro objetivo

Nuestro objetivo es desarrollar una página web entretenida y fácil de utilizar, mientras aplicamos los conocimientos adquiridos durante nuestra formación en programación.

Queremos que cualquier persona pueda entrar, elegir un juego y pasar un buen momento de una manera sencilla y agradable.
